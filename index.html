Permissões: atendente × solicitante

A regra central é: atendente é staff ou membro do grupo Atendentes. Centralizar isso em um arquivo evita espalhar regras de autorização pelo projeto.

from django.contrib.auth import get_user_model
from django.contrib.auth.mixins import LoginRequiredMixin, UserPassesTestMixin
from django.db.models import Q

AGENT_GROUP = "Atendentes"

def is_agent(user):
    if not user.is_authenticated:
        return False
    return user.is_staff or user.groups.filter(name=AGENT_GROUP).exists()

def agents_queryset():
    User = get_user_model()
    return User.objects.filter(
        Q(is_staff=True) | Q(groups__name=AGENT_GROUP),
        is_active=True
    ).distinct()

class AgentRequiredMixin(LoginRequiredMixin, UserPassesTestMixin):
    def test_func(self):
        return is_agent(self.request.user)

Models e regras de status

O domínio é formado por Category, Ticket e Comment. Um chamado fechado é final, e as transições permitidas ficam explícitas no model.

Aberto→Em atendimento→Aguardando→Resolvido→Fechado 
TRANSITIONS = {
    "open": {"in_progress", "closed"},
    "in_progress": {"waiting", "resolved", "closed"},
    "waiting": {"in_progress", "closed"},
    "resolved": {"in_progress", "closed"},
    "closed": set(),
}

def can_change_to(self, new_status):
    return new_status == self.status or new_status in self.TRANSITIONS[self.status]

Entidades principais

  • Category: nome único da categoria.
  • Ticket: título, descrição, categoria, prioridade, status, solicitante, responsável e timestamps.
  • Comment: autor, mensagem, indicação de nota interna e data.

Formulários

Há três formulários: abertura de chamado, comentário e gerenciamento. O campo de nota interna só fica disponível para atendentes, e o status passa pela validação das transições.

class TicketForm(forms.ModelForm):
    class Meta:
        model = Ticket
        fields = ["title", "category", "priority", "description"]

class CommentForm(forms.ModelForm):
    class Meta:
        model = Comment
        fields = ["body", "internal"]

class ManageForm(forms.ModelForm):
    class Meta:
        model = Ticket
        fields = ["status", "priority", "assignee"]

Views e segurança de visibilidade

A função visible_tickets é o coração da segurança: solicitante vê apenas seus chamados; atendente vê todos.

def visible_tickets(user):
    qs = Ticket.objects.select_related(
        "category", "requester", "assignee"
    )
    return qs if is_agent(user) else qs.filter(requester=user)

Na tela de detalhe, comentários internos são filtrados para que nunca apareçam para solicitantes.

comments = self.object.comments.select_related("author")
if not agent:
    comments = comments.filter(internal=False)

O fluxo de atendimento também permite assumir um chamado; se ele estiver aberto, passa automaticamente para Em atendimento.

Rodar e testar manualmente

python manage.py runserver
  1. Crie ana com e-mail preenchido no admin.
  2. Crie carlos e coloque-o no grupo Atendentes.
  3. Entre como ana em /contas/login/ e abra um chamado.
  4. Entre como carlos e clique em Assumir chamado.
  5. Adicione uma nota interna e depois uma resposta normal.
  6. Confirme que ana vê a resposta, mas não a nota interna.
  7. Teste transições inválidas de status.
  8. Teste que outro solicitante recebe 404 ao tentar acessar chamado alheio.

TROUBLESHOOTING

Problemas comuns

TemplateDoesNotExist

Confira a pasta tickets/templates/tickets/ e se tickets está no INSTALLED_APPS.

NodeNotFoundError na migration 0002

Gere a 0001_initial primeiro e só depois coloque a migration de seed.

Logout retorna 405

O fluxo usa POST. Utilize o botão de sair, não um link GET.

403 ao assumir ou gerenciar

O usuário precisa ser staff ou pertencer ao grupo Atendentes.

Atendente não aparece como responsável

Ele precisa estar ativo e ser atendente.

Nenhuma categoria no formulário

Execute python manage.py migrate ou cadastre categorias pelo admin.

E-mail não aparece no terminal

Preencha o e-mail do usuário e mantenha o servidor rodando com a configuração de e-mail de desenvolvimento.
